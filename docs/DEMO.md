# One-minute demonstration guide

Prepare the server, browser and Postman beforehand. Practice the sequence; the final recording must not exceed one minute. Do not show `.env`, terminal secrets or database passwords.

| Time | Show |
| --- | --- |
| 0–5 seconds | Running server terminal and browser dashboard |
| 5–17 seconds | Create a call using the frontend, with the form mostly prepared |
| 17–23 seconds | List cards and open the new call's complete details |
| 23–32 seconds | Edit the positions and save |
| 32–38 seconds | Close the call and show its Closed badge |
| 38–45 seconds | Delete the call and confirm disappearance |
| 45–60 seconds | Postman requests/responses: three creates, list/get, update/close/delete, deleted record 404 and invalid request 400 |
